# Veronica – Personal Virtual Assistant

Veronica is a Python-based personal virtual assistant designed to provide useful information and simplify everyday tasks through a simple voice-based interaction system.

## Features

- **Virtual Assistant:** Performs assistant-related tasks through Python.
- **Weather Updates:** Retrieves weather information.
- **News Updates:** Provides the latest news.
- **Modular Structure:** Uses separate Python files for different functionalities.

## Technologies Used

- Python
- Python Libraries (refer to requirements.txt)
- APIs for weather and news services

## Project Structure

```text
Veronica-Virtual-Assistant/
│
├── Virtual Assistant.py
├── news.py
├── weather.py
├── requirements.txt
└── .gitignore
```

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/sanjanachavann/Veronica-Virtual-Assistant.git
```

**2. Navigate to the project folder**

```bash
cd Veronica-Virtual-Assistant
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python "Virtual Assistant.py"
```
